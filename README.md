# 💕 FriendCalc

FriendCalc is a fun and interactive **Friendship Calculator** that generates a playful friendship score based on two names. 🤝💖

## 🌐 Live Website

https://raghunandan-22.github.io/FriendCalc/

## ✨ Features

- 👤 Enter two names
- 💯 Generate a friendship score
- 💕 Fun and interactive experience
- 🎨 Simple and clean interface
- 📱 Works on different screen sizes
- ⚡ Fast and lightweight

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and design
- **JavaScript** — Friendship score calculation and interactivity

## 📂 Project Structure

```text
FriendCalc/
│
└── index.html
```

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/Raghunandan-22/FriendCalc.git
```

Open the project folder:

```bash
cd FriendCalc
```

Then open `index.html` in your web browser.

## 🎯 Project Purpose

This project was created to practice **HTML, CSS, and JavaScript** while building a simple interactive web application.
